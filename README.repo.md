# 荒野行动 Plus 服务端

针对《荒野行动 Plus》3.0.43 客户端的本地实验服务端。仓库包含 SDK 授权、账户服务、大厅 UDP、BaseApp 通道协议、资源解码器和相应测试。

## 当前状态

- 原版 3.0.43 客户端已在本地加载 hukou 地图、默认角色、装备和第三人称镜头；用户确认可以移动和跳跃，位置日志同时验证了移动。
- 已从关闭的客户端通过一键脚本重新启动并自动进图。移动、开门、翻越矮墙、枪械弹药与换弹、练习目标命中扣血及倒地重生已通过实机验证。
- 已接入原生跳伞、开伞和落地流程；物资在原地图刷新点附近按区域加载，支持枪械、弹药、背包的拾取和丢弃。用户已确认跳伞、物品名称和丢弃正常。
- 已接入本地运输机投放、原生用药动作和车辆进出驾驶。程序验证了登机跟随、离机自由落体、开伞、落地和飞机回收；车辆、打药及背包操作也有用户实测记录。
- 已接入原生 AvatarRobot 的本地战斗控制：最多同时两个敌人，可接近视线内的玩家、开火、换弹；伤害经过原生子弹碰撞和护甲数据。练习模式默认暂停 AI，按 F5 启用后，玩家死亡约 8 秒恢复。
- 按 F10 开始或重新开始 9 人单机对局：运输机投放、落地后五阶段缩圈、圈外伤害、有限敌人、剩余人数和原版结算。对局中死亡直接结算，最后一名存活者获胜，F6 恢复仅在练习模式可用。
- 无人值守实机验证已完成一局 8 次原生枪械击倒，结算第 1 名、8 击杀、剩余敌人 0，并通过 F10 重开、登机、离机、开伞、落地复验。仓库 114 项自动测试通过。
- 当前为本地单机实现，复杂绕障和完整在线大厅尚未实现。物资池包含药品、能量物品、配件、护甲和背包，全部物品的效果仍需逐项验证。
- SDK、账户、大厅 UDP 与 BaseApp 为实验实现。离线模式通过可恢复资源补丁调用原客户端逻辑，并补齐界面等待、角色状态和本地模型位置同步。

## 启动

本机安装位置为 `I:\hyxd\hyp`，服务端目录为 `_local_server`。脚本保留了该机器的路径及 Python 运行时路径；迁移到其他位置时需要调整 `start_offline.ps1` 和 `offline_bootstrap.py`。

在游戏目录中部署本仓库为 `_local_server`，安装 Python 3 和 `requirements.txt` 中的依赖后运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File _local_server/start_offline.ps1
```

脚本校验并安装离线补丁，启动本机服务及原启动器，再使用启动器的实际窗口句柄启动客户端。保留原游戏文件和 `_local_server/backups/entities.before-offline-start.pg`；该备份由补丁首次运行时创建，不包含在仓库中。

启动并加载地形后显示原版大厅菜单。菜单保留当前战场背景，以避开旧客户端切换独立大厅场景时的渲染故障。点 **开始游戏** 进入本地单机对局，右上角齿轮打开原版设置。结算可返回菜单，在地面时也可按 **F11** 返回。菜单里按 **F6** 进入自由练习。组队、排行榜、商城等在线功能仍需独立服务支持。

进图后按 **F8** 开始一次高空投放，空中按 **F** 开伞；接近地面时保留原生自动开伞与落地检测。地上物品沿用原生 **F** 拾取和背包操作，普通刷新点被拾取后约 120 秒补充；主动丢弃的物品不重复增生。

按 **F9** 开始运输机投放。飞机从地图一侧飞向另一侧，小地图和大地图显示实时位置。登机后进入可跳伞区间时按 **F** 离机，航线末段会自动离机。**F7** 可在附近重新生成一辆车辆；车辆刷新与地面物资模型均有数量和加载预算限制。

**F10** 开始或重新开始单机对局。新对局恢复首次开局保存的装备，并补齐弹匣与每种枪械的有限备用弹药；不会在同一局中自动补弹。飞机上按 **F** 离机，空中按 **F** 开伞；落地后开始缩圈与敌人刷新。敌人共 8 名，最多同时存在 2 名，以控制性能开销。结算不会自动关闭客户端。

**F5** 暂停/启用本地 AI 战斗，**F6** 在练习模式恢复玩家并回到最近的地面检查点。练习复活保留库存；原有弹药耗尽后仍需拾取弹药。`verify_offline_battle.py` 与 `verify_offline_round.py` 是显式无人值守诊断工具，不会在正常启动时自动开火或强制开局。

关闭游戏后恢复原资源：

```powershell
python -B _local_server/offline_client_patch.py --restore
```

单独启动实验协议服务：

```powershell
python -B local_stack.py
```

服务监听 `127.0.0.1:443`、`18443`、`8766`、`25000` 和 `25100`。大厅与 BaseApp 的实体初始化依赖本机运行中的客户端会话信息，属于实验性实现。
